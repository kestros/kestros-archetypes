Step 10

Services

Every step so far rendered content that was sitting on the page. A component often needs something that is not - a product list, a search result, the current user - and that comes from an OSGi service in your project's core module, reached through a Sling Model.

The three pieces

  • An interface in api, so that the component depends on a contract rather than an implementation.
  • An implementation in core, annotated as an OSGi component so the container registers it.
  • A Sling Model adapting the component's resource, holding the service and exposing what the view needs.

Why the view stays simple

The view calls one property on the model and renders it. Keeping the work on the Java side is what lets every framework in this tutorial provide a different view of the same component without any of them re-implementing how the data was fetched.

The generated project ships a SampleService and a SampleModel in those two modules as a starting point.
