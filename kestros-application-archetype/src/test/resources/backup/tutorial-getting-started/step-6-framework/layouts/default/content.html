Step 6

Layouts

Every step so far changed the page by changing the framework. A Layout changes one component without touching the framework at all: the framework provides several views for the same ComponentType, and each component on the page picks the one it wants.

This framework provides two of them, default and more-info. You are reading default, which is the one a component gets when it has asked for nothing. That is why a framework that provides layouts must always provide a default - it is the fallback, not just the first entry in a list.

Switching this component's layout

  1. Click Edit in the Actionbar, then click this component.
  2. Open its dialog and choose the more-info layout.
  3. Save. Only this component changes - the page's framework is untouched.

In your codebase the two views sit side by side at src/content/jcr_root/apps/${artifactId}/components/tutorial-getting-started/step-6-framework/layouts.
