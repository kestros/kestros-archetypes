Step 7a

Variations

A Variation is a CSS class a framework offers for a component, with the stylesheet that backs it. An author turns one on in the component's dialog; nothing about which view renders changes.

Grouped Variations

Variations are declared inside a named group - this framework has theme and font-style. The group is what the dialog shows as a heading, and it is how the author is told which choices belong together.

Mutually Exclusive Groups

A group marked mutually exclusive lets one variation be on at a time, which is what theme wants - light and dark cannot both apply. A group that is not, like font-style, lets bold and underline be combined.

Inline Variations

An inline variation writes its CSS into the page rather than into the framework's stylesheet. Reach for it when the rule only matters where the variation is used, and you would rather not ship it to every page the framework renders.

Turn some on in this component's dialog and watch the page. Each one is a directory under step-7-framework/variations in your codebase.
