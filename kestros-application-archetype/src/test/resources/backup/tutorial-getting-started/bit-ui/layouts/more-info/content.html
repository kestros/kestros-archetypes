Your framework's more-info layout

The second of the two layouts ${artifactIdShorthand}-ui provides for this ComponentType. A framework that offers a choice has to offer at least two, and the other one has to be called default, because that is what a component gets when it has asked for nothing.

Both of them live at src/content/jcr_root/apps/${artifactId}/components/tutorial-getting-started/${artifactIdShorthand}-ui/layouts. Add a third directory there and it appears in this component's layout picker with no other change anywhere.
