Step 5c

What Changed

You are on version 3.0.0 of the Step 5 framework, and this markup came with it. Version 2.0.0 declared no view, so it showed you 1.0.0's page - the same fallback you saw when the library was the thing being versioned.

The panel beside this one shows the whole chain: the library views underneath, the framework views on top, and the one actually rendering the page in plain text rather than italics.

Next Step

Next we will look at layouts - several views on one framework, chosen per component rather than per page.

  1. Click Edit in the Actionbar at the top of the page.
  2. In the Edit Page dialog, click the Styles tab.
  3. Select Step 6: Layouts, and the Default theme.
  4. Click Save to apply the changes.
