Step 5a

Try the Other Two Versions

Step 4 versioned the library. This step versions the framework, and it behaves the same way. Switch between these in the Styles tab before moving on:

  • Using Framework Versions (Step 5) 2.0.0 - declares no view of its own, so it falls back to this one.
  • Using Framework Versions (Step 5) 3.0.0 - declares its own view, so the page changes.

Versioning the framework is what lets an existing site stay on the markup it was built against while new sites pick up the newest version.

Next Step

Next we will look at layouts - several views on one framework, chosen per component rather than per page.

  1. Click Edit in the Actionbar at the top of the page.
  2. In the Edit Page dialog, click the Styles tab.
  3. Select Step 6: Layouts, and the Default theme.
  4. Click Save to apply the changes.
