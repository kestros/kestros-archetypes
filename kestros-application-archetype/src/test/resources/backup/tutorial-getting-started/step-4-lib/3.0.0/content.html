Step 4c

What Changed

You are now on version 3.0.0 of the Step 4 framework, which references version 3.0.0 of the Step 4 library - and that version declares a view of its own, so this markup replaced the one 1.0.0 provided. Version 2.0.0 declared no view at all, which is why it showed you the 1.0.0 page.

The panel beside this one lists every view in play, with the ones that were overridden in italics. Nothing about the page's content changed through any of it; only the framework version did.

Next Step

Next we will version the framework itself rather than the library it depends on.

  1. Click Edit in the Actionbar at the top of the page.
  2. In the Edit Page dialog, click the Styles tab.
  3. Select Using Framework Versions (Step 5) 1.0.0, and the Default theme.
  4. Click Save to apply the changes.
