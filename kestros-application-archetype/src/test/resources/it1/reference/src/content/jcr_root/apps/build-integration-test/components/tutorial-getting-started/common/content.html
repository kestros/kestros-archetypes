Component Types

A ComponentType is block of content that can be dropped onto a page. This ComponentType can be found in your codebase at application/src/content/jcr_root/apps/build-integration-test/components/sample-component.

Each ComponentType can contain any number of ComponentViews, that can be provided for each Library or UIFramework. This allows you to simply change the UIFramework that is being used to render a page, and the layout, styles and behavior of the page will automatically update, with having to create a new site or migrate any content!

Documentation for ComponentTypes is automatically generated, and provides usage information as well as validation to help you troubleshoot potential development issues.

UI Frameworks

UIFrameworks are used to provide CSS and JavaScript to a page, as well as determine which ComponentViews will be used when a page is being rendered. Right now, this page is using the UIFramework named Empty Framework. It does not reference any Libraries, provide any of its own CSS or JavaScript, or provide any ComponentViews.
