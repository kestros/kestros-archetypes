UI Libraries

A UI Library is a modular frontend library that can be used across any number of UI Frameworks. Each UI Library can contain any of the following:

  • CSS
  • JavaScript
  • HTL Templates
  • Component Views

When a UI Framework includes a UI Library, it will automatically include all of the CSS, JavaScript, and other resources that are provided by the UI Library. In the case of HTL Templates and ComponentViews, the functionality can be overridden, either by other included libraries, or the UI Framework itself.

Providing Component Views with UI Libraries

Component Views can be provided by UI Libraries so that the markup travels with the CSS and JavaScript that styles it. Any UI Framework that includes the library gets the view, without that framework having to declare anything itself.

When to Provide Views with Libraries

Put a view on the library when the markup belongs to the library - a grid, a card, a carousel. Put it on the framework when the markup is specific to one site's design. Anything on the framework wins over anything the libraries it includes provide.
