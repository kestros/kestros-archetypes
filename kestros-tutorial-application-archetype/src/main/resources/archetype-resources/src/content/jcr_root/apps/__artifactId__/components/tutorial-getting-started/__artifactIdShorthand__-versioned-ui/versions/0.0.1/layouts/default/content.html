The same view as ${artifactIdShorthand}-ui's, but owned by a version rather than by the framework itself. ${artifactIdShorthand}-versioned-ui is a ManagedUiFramework: it holds versions and nothing else, and a page is themed against one of those versions rather than against the framework.

This is the shape steps 4 and 5 walked through, applied to your own project. Cut 0.0.2 by copying this directory, and every site still themed against 0.0.1 keeps rendering exactly what it renders today.
