Step 7b

Variations, from the other layout

This is the more-info layout of the same framework, and every variation you turned on is still on. That is the point worth taking from step 7: a variation belongs to the framework, not to the view, so switching layout does not reset it.

Grouped Variations

The dialog groups them the same way here, because the groups are declared once on the framework and every layout sees the same set.

Mutually Exclusive Groups

Still one theme at a time, still any combination of font-style. The constraint is on the group, not on the markup rendering it.

Inline Variations

An inline variation's CSS follows the component onto whichever layout is rendering it, for the same reason.

Switch back to default with the layout picker in this component's dialog when you have finished comparing them.
