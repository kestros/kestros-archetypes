This view belongs to your own framework

Everything else in this tutorial is rendered by one of the eleven tutorial- frameworks that shipped with it. This one is different: it is the view for ${artifactIdShorthand}-ui, the framework your own project owns.

You are reading its default layout. It is here so that the tutorial component still renders once you point a page at your framework rather than a tutorial one - and so that you have a working example to copy when you write the first view of your own.

Delete this directory along with the rest of the tutorial when you are finished with it. Step 11 says how.
