Step 10

Datasources

The card below is not stored anywhere in this project's content package. Its title and its description are built in Java, by TutorialCardDataSource, and handed to the standard Kestros Card component at render time.

The wiring is two nodes and one class:

  1. TutorialCardDataSource extends BaseContainerSlingModelDataSource and implements KestrosCard. It is a Sling Model, so it needs no OSGi service registration.
  2. A node under /apps/kestros/commons/components/content/card/datasources names that class in its classPath property. That is what makes the datasource selectable on a Card.
  3. The Card instance on this page carries kes:datasource="${artifactId}-tutorial-card", which is the name of that node.

Change what the card says

  1. Open src/main/java/${packageInPathFormat}/application/datasources/TutorialCardDataSource.java.
  2. Edit the string returned by getDescription().
  3. Rebuild and redeploy the application module, then reload this page. The new text is on the card, and nothing in the content package changed.
