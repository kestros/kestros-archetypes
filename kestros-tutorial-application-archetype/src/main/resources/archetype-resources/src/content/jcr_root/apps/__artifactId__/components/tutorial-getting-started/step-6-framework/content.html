Step 6

Themes

Every step so far has asked you to pick a framework and a theme, without saying what the theme was doing. This step is that answer.

A Theme is a child of a UIFramework, and it supplies the CSS that framework serves to the page. The framework decides which ComponentViews render - which words you see - and the theme decides how those words look. Nothing else about the page changes when you change the theme.

This framework, Step 6: Themes, ships two of them:

  • Default Theme, at application/src/content/jcr_root/etc/ui-frameworks/tutorial-step-6-framework/themes/default
  • High Contrast Theme, at application/src/content/jcr_root/etc/ui-frameworks/tutorial-step-6-framework/themes/high-contrast

They differ by one file each - the .less under the theme's css node.

A theme is not a component variation

Two steps from here, Step 8: Variations introduces a variation group called Color/Theme. Despite the name it is a different thing. A variation is declared by a ComponentType and restyles that one component wherever an author switches it on. A theme belongs to a UIFramework and restyles the whole page, for every component on it, and it is chosen once in the page's Styles tab rather than per component.

That is why the themes here are named Default and High Contrast and not Dark and Light: those two words are already taken by the Color/Theme variation you will meet at step 8.

Try It

Keep the same framework selected and change only the theme. The instructions and the layout will not move; the colours will.

  1. Click Edit in the Actionbar at the top of the page.
  2. In the Edit Page dialog, click the Styles tab.
  3. Leave Step 6: Themes selected as the framework, and change the theme to High Contrast Theme.
  4. Click Save to apply the changes.

You are reading the same view either way. Open the framework's stylesheet to see which theme served it:

  • CSS for the Default Theme
  • CSS for the High Contrast Theme
