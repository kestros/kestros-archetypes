Try the Other Two Versions

This framework ships in three versions, and each one references a different version of the Step 4 library. Before moving on, switch between them in the Styles tab and watch what happens to the page:

  • Versioned Framework (Step 4) 2.0.0 - the library's 2.0.0 declares no view, so the page falls back to the 1.0.0 view you are reading now. The panel beside this one is how you can tell.
  • Versioned Framework (Step 4) 3.0.0 - 3.0.0 does declare a view, so the page changes.

That fallback is the point of the step: a version only has to provide what it changes, and everything else keeps resolving to the newest earlier version that provided it.

Next Step

Next we will version the framework itself rather than the library it depends on.

  1. Click Edit in the Actionbar at the top of the page.
  2. In the Edit Page dialog, click the Styles tab.
  3. Select Using Framework Versions (Step 5) 1.0.0, and the Default theme.
  4. Click Save to apply the changes.
