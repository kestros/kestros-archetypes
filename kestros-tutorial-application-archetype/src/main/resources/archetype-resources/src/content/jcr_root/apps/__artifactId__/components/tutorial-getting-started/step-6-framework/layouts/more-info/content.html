Step 6

You are reading the more-info layout

Same component, same content, same framework - a different view. Nothing on the page changed except which of this framework's layouts this one component asked for.

What layouts are good for

  • Different HTML structures for the same ComponentType - a list here, cards there.
  • A hard-coded variation configuration you do not want authors to have to set each time.
  • Denser or sparser presentations of the same data, chosen per placement.

What they are not

A layout is not a version and it is not a framework. It cannot change what data the component reads, and it only exists for the framework that declares it - switch the page to a framework with no more-info layout and this component falls back to that framework's default.

Switch back with the layout picker in this component's dialog.
