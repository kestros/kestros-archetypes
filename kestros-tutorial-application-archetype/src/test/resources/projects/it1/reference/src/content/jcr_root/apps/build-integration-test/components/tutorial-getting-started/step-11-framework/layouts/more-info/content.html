Step 11

Datasources

A datasource is chosen per component instance, not per component type. The same Card component renders authored content when kes:datasource is absent, and programmatic content when it names a registered datasource.

Only the datasource node's classPath ties the two together, so a datasource can be swapped for another without touching the page, and a component view never references a datasource class directly.

container="{Boolean}true" on the registration node is what marks this datasource as supplying a container element - a Card - rather than a single value such as a string of text.
