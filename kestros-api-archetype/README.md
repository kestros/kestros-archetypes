# Kestros API Archetype

This archetype is used to create a new Kestros API module. This module is used to define the data model interfaces for
Kestros projects.

## Usage

```
mvn archetype:generate                                  \
  -DarchetypeGroupId=io.kestros.cms   \
  -DarchetypeArtifactId=kestros-api-archetype       \
  -DarchetypeVersion=0.9.0
```
