# Build Integration Test

This is a project generated by the Kestros Maven Archetype. This project is intended to be used as a
starting point for building a new project. The project is broken into several modules, each with a
specific purpose.

## Modules

| Module      | Description                                                                                                                                                                                                                                               |
|-------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| api         | Model and service definitions.                                                                                                                                                                                                                            |
| core        | Contains core service and model implementations. Generally, classes within the core module should not execute independently but should only run when invoked by an application or other core modules.                                                     |
| application | Code that handles user interactions and requests, invoking core services and models as needed to fulfill application-specific functionality. This includes, components, servlets, and jobs, as well as page templates, frontend libraries and frameworks. |
| content     | Initial content installation. Generally creates site resources, but not specific pages.                                                                                                                                                                   |

## What this project demonstrates

The generated project is a working tour of the Kestros building blocks. Each example is intentionally
small: find it, change it, redeploy.

| Example | Where |
|---------|-------|
| Custom component (definition, edit dialog, Sling Model, common view) | `application`: `apps/build-integration-test/components/sample-component`, `SampleComponent.java` |
| Component views per UI Framework, layouts, and variations | `application`: `sample-component/bit-ui` (layouts + variations) and `bit-versioned-ui` |
| Component view attached by a VENDOR LIBRARY rather than a framework | `application`: `apps/kestros/commons/components/content/text/bit-versioned-lib/versions/0.0.1`, on the core Text component. It is carried by `build-integration-test-versioned-library`, so switch the site's theme to the versioned framework to see it render; under the unversioned framework Text keeps its `common` view |
| UI Library (unversioned + versioned) | `application`: `etc/vendor-libraries/build-integration-test-library` and `build-integration-test-versioned-library` |
| UI Framework (unversioned + versioned, with themes) | `application`: `etc/ui-frameworks/build-integration-test-framework` and `build-integration-test-versioned-framework` |
| OSGi service consumed by models and datasources | `api`: `SampleService`, `core`: `SampleServiceImpl` |
| Datasource feeding a list component | `application`: `SampleCardListDataSource`, registered on the Card List component by `apps/kestros/commons/components/lists/card-list/datasources/build-integration-test-sample-cards`, selected on the sample site page via the `kes:datasource` property (`content` module) |
| Datasources for other component types (Table, single Card, Button, Text) | `application`: `SampleTableDataSource`, `SampleCardDataSource`, `SampleButtonDataSource`, `SampleTextDataSource` in `datasources/`, each registered on its component and selected via `kes:datasource` |
| Component view that OVERRIDES a datasource | `application`: `apps/kestros/commons/components/lists/card-list/bit-versioned-ui`; switch the site's theme to the versioned framework to see it take over |

| Page templates | `application`: `apps/build-integration-test/templates` |
| Sample site content wiring it all together | `content`: `content/sites/build-integration-test` |

## Building and Installing

For more information regarding build profiles available to each module, see their respective
README.md files.

```
mvn clean install -P,installBundle
```

The following connection properties can be overwritten:

| Property       | Default Value |
|----------------|---------------|
| sling.host     | localhost     |
| sling.port     | 8080          |
| sling.protocol | http          |
| sling.user     | admin         |
| sling.password | admin         |
